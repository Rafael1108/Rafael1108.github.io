# Rafael Larrea — Portfolio V2

Portafolio estático bilingüe, responsive y apto para GitHub Pages.

## Publicación
1. Crear repositorio público `Rafael1108.github.io` en GitHub.
2. Subir el contenido de esta carpeta a la raíz de la rama `main` (no la carpeta contenedora).
3. Ir a Settings > Pages > Build and deployment > Deploy from a branch > `main` / `(root)` > Save.
4. Visitar `https://rafael1108.github.io/`.

## Notas
- La sección GitHub obtiene repositorios públicos mediante la API de GitHub al cargar la página. Requiere conexión a internet y está sujeta a límites públicos de la API. No representa necesariamente el inicio real de cada proyecto.
- La línea de tiempo histórica se elaboró a partir de los dos CV aportados.
- Los proyectos empresariales no implican disponibilidad de código fuente.
- No se incluye el CV original completo por contener información personal no necesaria para un sitio público.
- No se requieren npm, backend ni base de datos.
